# libSceIcu technical debt

### Functional

- [UTF-32 and Java modified UTF-8 conversions](../../../core/libs/prx/libSceIcu/Utf32Conversions.cpp): exact PS5 version equivalence remains unverified. Six exports follow ICU 78.1 [ustrtrns.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/ustrtrns.cpp), including strict/substitution handling, error and optional-output ordering, preflight, whole-pair UTF-32 writes and termination warnings. Java modified UTF-8 encodes surrogate halves separately and NUL as C0 80; its decoder accepts the source-defined overlong and surrogate sequences. Null conversion error pointers and required lengths outside the signed 32-bit API throw. Source and destination must not overlap, as required by ICU. Other ICU functions remain unimplemented.

- [Modified UTF-8 supplementary substitutions](../../../core/libs/prx/libSceIcu/ModifiedUtf8.cpp): console behavior remains unmeasured. The pinned ICU 78.1 source counts an invalid sequence as one UTF-16 unit while preflighting an unwritten supplementary replacement, but counts both units when it writes all or part of the pair. The host retains this capacity-dependent length and partial leading-surrogate write rather than substituting ordinary UTF-8 behavior. Malformed sequence consumption follows the pinned `utf8_nextCharSafeBody` logic.

- [String termination](../../../core/libs/prx/libSceIcu/StringTermination.cpp): exact PS5 warning/error equivalence is unverified. The four exports follow ICU 78.1 [ustring.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/ustring.cpp), preserving incoming failures and negative lengths, treating a null error pointer as a no-op, and setting not-terminated or overflow status from capacity. A null destination requiring a write throws. Guest `wchar_t` is explicitly 16 bits, following LLVM's PS4/PS5 `UnsignedShort` target definition in [OSTargets.h](https://github.com/llvm/llvm-project/blob/llvmorg-21.1.0/clang/lib/Basic/Targets/OSTargets.h#L494-L563); host `wchar_t` width is not used.
