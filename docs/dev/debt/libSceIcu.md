# libSceIcu technical debt

### Functional

- [ICU hash tables](../../../core/libs/prx/libSceIcu/HashTable.cpp) - PS5 version, allocation geometry and callback/element ABI are unverified. The ten pointer-table APIs follow ICU 78.1 [uhash.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/uhash.cpp) and [uhash.h](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/uhash.h): 80-byte table allocation, 24-byte returned elements, 8-byte tokens, one-byte comparator results and guest SysV callbacks. Windows, macOS and console execution remain untested. Tables must originate from this implementation's `uhash_open`; native tables, copied private layouts and caller-provided `uhash_init` storage are unsupported.
- [Hash-table argument handling](../../../core/libs/prx/libSceIcu/HashTable.cpp) - null required status/callback/table pointers and iteration positions causing invalid indexing or signed overflow throw where upstream requires valid inputs. Integer-key/value APIs and resize-policy setters are not implemented. The default growth policy, including the pinned source's retained prime index after allocation failure, is followed without PS5 verification. The shared [ICU allocator state](../../../core/libs/prx/libSceIcu/Memory.hpp) follows pinned [cmemory.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/cmemory.cpp); interoperability with external ICU allocator state is unverified.
