# libSceIcu technical debt

### Unknown function info

- [ICU export availability](../../../core/libs/prx/libSceIcu/Unescape.cpp) across firmware versions remains unproven. The [PS5 3.20 inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceIcu.c) includes the implemented escape, invariant-character and version helpers. [BunnyFl’s firmware 13.42 report](https://github.com/boykopovar/AnyPS5/pull/10961#issuecomment-6400071863) records `u_getVersion` returning `78.1.0.0` under an emulator, but neither escape function is in the checked native `system_ex/common_ex/lib/libSceIcu.sprx` export table. Only 104 of the 661 inventory NIDs appear among that module’s 299 exports. The exports for compatibility with older firmware are retained; availability and routing across firmware versions remain unproven.

### Functional

- [Escape decoding](../../../core/libs/prx/libSceIcu/Unescape.cpp) has no behavior or ABI verification on console hardware. It follows ICU 78.1's [ustring.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/ustring.cpp), including rejection of eight-digit braced hexadecimal escapes although its public header advertises up to eight digits. Null source or offset pointers, null callbacks with an in-range offset, negative capacity with a nonnull destination and source lengths exceeding `INT32_MAX` throw. Null-destination preflight ignores capacity. Closes when: compared with the console, including callback ABI, byte conversion, capacity limits and braced hexadecimal parsing.

- [Invariant character and version helpers](../../../core/libs/prx/libSceIcu/Version.cpp) are unverified on a console. `u_charsToUChars`, `u_UCharsToChars`, `u_versionFromString`, `u_versionFromUString` and `u_versionToString` follow ICU 78.1 [uinvchar.cpp](https://github.com/unicode-org/icu/blob/release-78.1/icu4c/source/common/uinvchar.cpp) and [putil.cpp](https://github.com/unicode-org/icu/blob/release-78.1/icu4c/source/common/putil.cpp), unchanged since 65.1. Firmware 13.42 reports ICU 78.1 and exports none of them ([#11013](https://github.com/boykopovar/AnyPS5/pull/11013#issuecomment-6400470698)); the [3.20 table](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceIcu.c) has all five. Version parts use the guest `strtoul`, truncated to eight bits; `u_versionToString` keeps ICU's dropped zero tens digit (105 becomes `15`). A null buffer with a positive conversion length throws; ICU dereferences it. Closes when: compared with the console.

- [UTF-16 scalar counting and search](../../../core/libs/prx/libSceIcu/Utf16.cpp): equivalence on console hardware is not established beyond the firmware 13.42 emulator cases below. The five APIs follow the stable public contracts and implementation of ICU 78.1 [ustring.h](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/unicode/ustring.h) and [ustring.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/ustring.cpp), including isolated-surrogate matches, counted embedded NULs, truncated pairs and invalid scalar rejection. Null search inputs that require a read and terminated counts beyond INT32_MAX throw; the public API does not define such valid inputs. Invalid buffers and overlapping concurrent modification remain caller errors.

- [UTF-16 scalar ABI](../../../core/libs/prx/libSceIcu/Utf16.cpp): argument and return type compatibility on console hardware remains unmeasured. Export names and NIDs are in the [PS5 3.20 inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceIcu.c). The adapter uses public ICU UChar as a 16-bit unit, UChar32 and lengths as signed 32 bits, UBool as signed 8 bits, and guest System V calling conventions; the inventory alone does not establish these types.

- [Firmware availability and conformance](../../../core/libs/prx/libSceIcu/Utf16.cpp): [BunnyFl’s firmware 13.42 report](https://github.com/boykopovar/AnyPS5/pull/10966#issuecomment-6400072800) records `u_getVersion` returning `78.1.0.0` with `system_ex/common_ex/lib/libSceIcu.sprx` run under an emulator. `u_countChar32` matched 94,111 bounded cases covering mapping ends, null text, negative and explicit lengths, NULs and surrogates. `u_strHasMoreChar32Than`, `u_strchr32`, `u_strrchr32` and `u_memchr32` are absent from that module’s exports. The 3.20 compatibility exports are retained; hardware equivalence and availability/routing across firmware versions remain unproven.
