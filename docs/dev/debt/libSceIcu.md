# libSceIcu technical debt

### Functional

- [Byte-string helpers](../../../core/libs/prx/libSceIcu/ByteStrings.cpp): the console ICU version and exact behavior are unverified. These exports follow ASCII/POSIX [ICU 78.1 cstring.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/cstring.cpp) and `putil.cpp`. Numeric formatting throws before writes for invalid radices, null output, decimal signed minima and results over 29 digits, where the reference asserts, negates a signed minimum or overflows its fixed scratch buffer. Parsing delegates the existing guest LP64 `strtoul` model and retains its locale/error gaps. Null duplication input and INT32_MAX counted duplication throw because the source dereferences null or overflows its signed allocation-size expression. Nonnegative counted duplication copies exactly that many bytes, including bytes after NUL; any negative count duplicates the terminated string.

- [Shared ICU allocation](../../../core/libs/prx/libSceIcu/Memory.hpp): console allocation policy, callback exceptions and calls outside ICU's documented pre-initialization setter contract remain unverified. The helper follows [ICU 78.1 cmemory.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/cmemory.cpp): callbacks share one context, zero allocations use a 24-byte constant block, freeing null still calls the configured callback, and zero-size reallocations free nonzero-block pointers. The setter preserves positive failure status, rejects missing callbacks with error 1 and otherwise replaces the configuration, without inventing a heap-use lock absent from that source. Null status throws. Defaults use the guest C allocator. Cleanup resets and concurrent callback replacement are not implemented.
